# Threat Dragon Threat Modelling

A repository for threat modelling using [OWASP Threat Dragon](https://threatdragon.org/).

## Overview

This project contains threat modelling artifacts and documentation created with Threat Dragon. Threat Dragon helps teams visualize system architectures, identify potential threats, and document mitigations.

## Getting Started

1. Install or open OWASP Threat Dragon.
2. Open the threat model files in this repository.
3. Review the system diagrams, identified threats, and recommended mitigations.
4. Update the model as the system evolves.

## Repository Contents

Add diagrams, threat model files, notes, and supporting documentation to this repository as the project develops.

## Contributing

Keep threat model changes clear and reviewable. Describe significant updates in commit messages or pull requests, and ensure new threats include appropriate mitigations where possible.
